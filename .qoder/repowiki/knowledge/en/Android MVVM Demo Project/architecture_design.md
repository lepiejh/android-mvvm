The root Gradle project declares two modules in `settings.gradle` — `:mvvm_library` (the reusable MVVM framework) and `:app` (the demo application) — and wires them together via a shared top-level `build.gradle` that applies `config.gradle`. All Kotlin version, Android SDK levels, Maven repositories (Aliyun, JitPack, Google, plus a private Nexus), and third-party dependency versions are defined centrally in `config.gradle`'s `ext` block so both child modules consume identical versions without hardcoding them. The `:app` module depends on `:mvvm_library`, forming a one-way dependency graph where the framework exposes APIs consumed by the demo.
