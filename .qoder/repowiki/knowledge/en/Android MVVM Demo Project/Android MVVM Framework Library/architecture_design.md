The module is an Android library (`com.android.library`) organized around the MVVM pattern. The `base` package defines the core contracts and base classes: `IBaseView`, `IModel`, `IRepository`, `IBaseViewModel` interfaces; `BaseActivity`/`BaseFragment` for DataBinding + ViewModel lifecycle; `BaseViewModel` (Kotlin) extending `AndroidViewModel` that owns a `CompositeDisposable`, manages background `Job`s via `viewModelScope`, exposes a `UIChangeLiveData` command facade (`UICommand`), and routes EventBus/RxBus messages through pluggable `IEventSubscriptionStrategy` implementations (`DefaultEventStrategy`, `StickyEventStrategy`). `binding/command` provides `BindingCommand` for XML-to-ViewModel action binding, while `binding/viewadapter/*` supplies data-binding adapters for RecyclerView, ListView, ViewPager, WebView, etc., built on top of `bindingcollectionadapter`. The `net` layer wraps Retrofit+OkHttp in `RetrofitClient` (singleton with DCL, builder-based per-call config) plus Gson converters and RxJava3 call adapter; `http` adds interceptors (logging, cache, progress), cookie stores, download manager, and a strategy registry for exception handling. `bus` offers both RxBus (RxJava) and EventBus (greenrobot) wrappers with sticky-event support. Supporting layers include `permission` (RxPermission wrapper), `crash` (CustomActivityOnCrash integration), `update` (XUpdate), `take` (camera), `widget` (custom Views), and a large `utils` package (Gson, MMKV, Glide, file/crypto/network helpers). Dependency direction flows from `base` → `binding`/`net`/`bus` → feature modules; `base` has no inward dependency on other packages.
